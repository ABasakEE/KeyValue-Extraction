# Presentation slides (source)

The deck is a Claude Slides artifact: https://claude.ai/artifact/RaNkaSm51jWZDzSwJrorrk
(private to its owner until shared from the page's Share menu).

This folder is a copy of its source: `deck.json` (title, slide order, sections, fonts) and one HTML file per slide in `slides/`, with speaker notes in each slide's `<aside>`. Images are referenced as `/_blob/<id>`, which only resolve inside the artifact; the same images are in `../figures/` and `../../slides/figures/`.

To get a file to submit, open the artifact and download it as .pptx (opens in Google Slides) or PDF.

18 content slides + 2 reference slides (the guidelines allow 18 excluding references).
