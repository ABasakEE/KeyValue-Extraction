Loss

L = L(tag) + λ · L(link), λ = 1. Links use focal loss (γ = 2, α = 0.75) because true pairs are rare among all entity pairs.

Decoding

Soft type prior (question→answer, header→question). Each value keeps only its best key, if p ≥ 0.5.

3-phase curriculum

① tagging only → ② encoder frozen, train the link head on gold spans → ③ joint, encoder LR × 0.2

Tagging tells us which words are keys and values, but it doesn’t say which value belongs to which key. The relation head scores every ordered pair of entities. The bilinear term compares what the two entities say, and the linear term adds 16 spatial relations we designed by hand. When we trained everything jointly from the start it was unstable, so we moved to a three-phase curriculum. We use focal loss because only a few percent of entity pairs are real links.
