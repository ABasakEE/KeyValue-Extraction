Preprocessing and template-disjoint splits

Preprocessing

  1. Word boxes scaled to integers in 0–1000; inverted boxes repaired
  2. BIO tags per word; only the first sub-word is scored
  3. Long documents cut into 384-word windows, 128 overlap
  4. Graph models: LiLT features + Delaunay edges cached per window
  5. Training-time coordinate jitter and content-box anchoring
