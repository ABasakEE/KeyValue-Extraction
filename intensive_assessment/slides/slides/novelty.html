Plan for novelty assessment (23 and 25 Nov)

1. Linking under template shift

No work we found measures key-value linking on held-out templates. Build that benchmark by holding out whole form families.

2. Template-adversarial LiLT

A gradient-reversal head that tries to predict the template id, pushing the encoder towards template-invariant features.

3. Relative 2-D attention

Replace absolute box embeddings with relative positions inside self-attention, as in BROS.

4. Learned graph edges

Let text similarity decide which words connect, instead of a fixed Delaunay triangulation.

Success test: a smaller unseen-template gap at the same seen-template F1, under the same matched N = 200 protocol.

Each idea targets a failure we measured. The adversarial head and relative attention attack position memorisation in LiLT; learned edges attack the brittle Delaunay neighbourhoods; the linking benchmark tests the part of the task no published work has evaluated under template shift.
